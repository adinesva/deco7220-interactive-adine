# Inside the Noise — Metalcore Genre Deep Dive

An interactive music data visualisation project exploring the sonic identity of the metalcore genre through audio features, emotional tone, lyrical content, and popularity patterns.

This project transforms Spotify track data into interactive and animated visual experiences to help users better understand the structure, mood, and characteristics of modern metalcore music.

---

# Project Overview

This project investigates how audio features such as energy, valence, loudness, danceability, speechiness, tempo, and lyrical explicitness shape the identity and popularity of metalcore tracks.

The visualisations were designed to support exploratory analysis through interaction techniques such as:
- Hover interactions
- Dynamic highlighting
- Filtering
- Progressive disclosure through tooltips

# Chart Overview

## Scatter Plot — Energy vs Valence
This visualisation explores the relationship between song energy and emotional positivity (valence). Interactive filters allow users to compare songs based on tempo and explicit or clean lyrics, helping identify emotional and energetic patterns within the dataset.

---

## Sankey Diagram — What Makes a Song Popular
The Sankey diagram visualises how song characteristics such as tempo, mood, and lyrical explicitness connect to popularity levels. Interactive highlighting and animated transitions help users follow relationships between different categories more clearly.

---

## Slope Chart — Song Feature Comparison
The slope chart compares multiple song features including loudness, valence, energy, speechiness, and danceability. The visualisation supports quick comparison of dominant audio characteristics while maintaining a clean and readable layout.

# How to Open the Project

## Run Using Live Server (Recommended)

1. Open the project folder in Visual Studio Code  
2. Install the **Live Server** extension  
3. Right click `index.html`  
4. Select **Open with Live Server**

---

## Alternative Method

Open the `index.html` file directly in a web browser.

For the best experience:
- Use Google Chrome
- Use desktop resolution
- Enable JavaScript
